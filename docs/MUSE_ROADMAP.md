# Muse 对标迭代路线

目标：从本地办公 Work Agent，逐步成为能持续推进目标、跨应用行动、保留个人上下文且受用户监督的个人 Agent。对标依据为 Meta 公开的 Muse 产品与安全设计；这里记录本项目的实现范围，避免把界面入口当成已完成能力。

## 已实现的第一批基础能力

- 长期目标、步骤、执行结果和活动记录持久化；目标可暂停、恢复、完成。
- 用户可修订尚未完成的步骤，已完成步骤保留原始执行记录。
- 用户可调整未完成步骤的顺序；已完成、排队和运行中的步骤占位不变。计划版本随添加、修订、接纳建议和重排递增，过期重排请求会被拒绝。
- 最后一个非定期步骤完成后生成复盘和后续步骤建议；建议经用户逐条接纳才会加入执行计划。
- 目标步骤在后端队列执行，支持手动启动以及每天固定时间或每 N 小时的计划。
- 目标队列最多并发执行 2 个不同目标的步骤（可由 `MAX_CONCURRENT_GOAL_TASKS` 调整，最高 8）；同一目标的步骤仍顺序执行，避免共享会话交错。
- 已接入公开 GitHub Release 的只读轮询触发：新版本 ID 与目标队列状态一起持久化，重复检查不重复执行；可用 ETag 避免无变化时重复解析。
- 浏览器关闭不会中断目标步骤；服务重启后，尚未产生工具调用且没有后续消息的规划阶段会自动重新入队，进入工具阶段的步骤标记为“已中断”供用户核对副作用。缺失的工具回复会补成“执行状态未知”的会话记录，不会重放操作。
- 定时任务重启恢复时，未完成的运行标为中断，并将下一次调度推到未来，避免重启后重复当次副作用。
- 普通会话、目标后台步骤和定时任务中的写文件、命令、外部工具操作默认自动放行，操作参数和结果持久化；可选手动审批模式。
- 自动模式截断过长的记录并保留摘要哈希；包含凭据字段的参数仍被拦截。
- 浏览器填写或点击默认自动执行，执行前复核真实页面和元素，结果留档。密码与支付字段的自动填写仍被拦截。
- 用户可维护个人或目标范围的记忆，并可编辑和删除。
- 目标可持有独立于聊天的可编辑文稿；用户编辑与 Agent 自动更新共用版本号，防止后台结果覆盖较新的用户修改。每份文稿保留最近 20 个旧版本、更新来源和恢复来源；恢复生成新版本，文稿及历史随目标状态持久化。
- 目标步骤成功生成的文件会进入目标文件清单，记录来源步骤、工具和工作区相对路径。100 MB 以内的文件保存独立的校验快照及最近 20 个旧版本；超限文件与升级前的旧索引仍使用实时工作区路径。
- 对话中的明确长期偏好可形成候选记忆；候选项保留用户原话和置信度，仅在用户确认后进入正式记忆与 Agent 上下文。
- 每条记忆可设为相关任务使用、始终提供或仅本地保存；旧记忆默认按当前任务的中英文词项匹配，目标记忆仅用于所属目标。自动网页读取拒绝本机、内网及指向这些地址的重定向。
- 提醒收件箱从持久化的审批、目标活动和定时任务运行记录生成；偏好与已读状态持久化，浏览器后台标签页可在用户授权后显示桌面通知。
- Google 日历主日历只读连接：桌面应用 OAuth + PKCE、回环地址回调、令牌持久化与刷新、断开时发起撤销；界面和 Agent 可读取最多 31 天内的事件。模拟 Google 端点的授权与重启测试已通过，真实账号端到端授权尚待用户验证。
- 目标步骤可监控未来七天的 Google 日历事件，每五分钟检查新增或更新；创建时先建立基线，事件版本与入队状态一同持久化，持久化失败不会吞掉事件。扫描翻页最多 500 条，超限报错；尚未覆盖两次轮询间创建后删除的事件。
- API 仅监听本机回环地址；取消宽松 CORS；模型密钥从主状态文件迁移到权限为 `0600` 的本地独立文件。以上仍不等同于独立凭据保险库。
- 自动文件读取和搜索校验符号链接真实路径，并排除已知凭据、运行时状态文件；命令子进程剥离常见凭据环境变量。自动执行的命令仍能访问本机文件系统，尚无真正沙箱。
- 状态迁移到带版本号的 SQLite 实体表；旧 JSON 首次导入后保留备份。单实例租约阻止两个本地进程相互覆盖状态。
- SQLite 当前在每次保存请求发起时固定实体快照，并以事务提交整批变更；同机进程存活时不因租约心跳过期而被第二实例接管。目标的每次工具调用前后保存启动与结果状态，工具阶段保存失败后标记待人工核对；尚未拆成可独立并发更新的任务记录。Node 内置 SQLite 仍处于 release candidate 阶段。

## 未完成的对标能力与验收条件

| 方向 | 待做 | 验收条件 |
| --- | --- | --- |
| 持久运行时 | 已有 SQLite 状态、调用时快照、单实例租约、跨目标并发队列和逐次工具启动/结果状态；仍需任务级租约、完整工具结果留档及跨进程安全恢复 | 服务意外退出后能恢复安全可重试任务，已有副作用的步骤明确待人工检查；并发运行不丢数据 |
| 目标自治 | 已支持人工修订、未完成步骤重排与后续建议；仍需周期性复盘及更强的证据引用 | 完成一步后能提出下一步及证据，用户可改计划，目标状态与执行记录一致 |
| 事件触发 | 已有文件变化、公开 GitHub Release 和 Google 日历近期变化轮询；仍需邮件、Webhook 和 Google 推送或完整增量同步 | 真实事件到达后只执行一次；重复事件、断线重连不会重复写入，短暂事件也不丢失 |
| 跨应用连接器 | 已有公开 GitHub Release 与 Google 主日历只读接入；仍需邮件只读，再加入草稿和写入 | 用真实账号完成 OAuth 授权、权限撤销、令牌刷新和端到端用例；邮件连接器可用 |
| 浏览器行动 | 已覆盖普通会话和后台目标的自动执行与留档；仍需结构化提交审查和接管体验 | 每次提交可审查目标和内容，敏感表单由硬性策略拦截，用户可接管 |
| 安全隔离 | 已拦截自动文件工具对已知敏感路径及符号链接越界的读取，并清理命令环境；仍需独立执行沙箱、网络出口策略、凭据代理、注入防护 | Agent 无法直接读取凭据；外部内容不能绕过硬性策略或向未授权地址传输私有数据 |
| 主动提醒 | 已有重要/全部/关闭模式、本地提醒收件箱与桌面通知合并限频；仍需系统常驻通知和移动推送 | 仅在新进展、失败或需要输入时提醒；支持关闭或调低主动性 |
| 个人记忆 | 已有候选提取、来源、确认、词项相关性筛选与逐条使用方式；仍需语义检索和独立隐私隔离 | 用户可查来源并修正；仅本地保存不自动加入模型上下文；删除后不再进入后续上下文 |
| 多端体验 | 后台服务常驻与移动端访问 | 关闭桌面浏览器后继续工作，手机可查看状态与执行记录 |
| 产物 | 已有目标内可编辑文稿、版本冲突保护、Agent 自动更新、最近 20 个旧版本的对比与恢复，以及步骤文件的版本化交付快照；仍需结构化交互组件、超限文件的归档策略与删除恢复 | 文稿独立于聊天保存，用户和 Agent 可持续编辑；文件快照从目标可下载，原文件变化或服务重启后仍可取得交付内容 |

## 建议先验证的三个完整场景

1. **持续研究**：设置目标，每天检查新资料，更新同一份报告，只在发现实质变化时通知。
2. **邮件与日历协助**：读取用户授权的数据，整理待办并生成草稿；发送和创建日程后保存操作与结果记录。
3. **项目推进**：目标拆解、后台执行、产物留档；浏览器关闭和服务重启后状态仍可靠。

当前版本覆盖第三个场景的基础部分，以及第二个场景中 Google 日历读取的代码路径。真实账号授权和邮件能力尚未验证。请勿将其描述为与 Muse 功能或安全等级完全等价。
